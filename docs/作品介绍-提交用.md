## 作品名称

**飞花音 —— 以歌为令，以字会友（异步音乐飞花令）**

## 一句话产品

一个字就是一个永久房间：随时进去唱一句带这个字的歌词，AI 自动识别原曲、当裁判、防重复；异步接力之外，还能拉好友实时 PK、抽技能卡、踩对方的"炸弹歌"。

## 作品简介（约 300 字）

飞花音把传统行酒令"飞花令"搬进音乐场景：**一个字 = 一个永久房间**，任何人随时进去唱一句带这个字的歌词即可接令，无需同时在线——花传到你，24 小时内接上就行，通勤、睡前、课间都能接。

AI 是房间里的全能判官：语音识别歌词出自哪首原唱、判定是否真带这个字、自动查重。相同歌词自动归并成"跟唱"（首唱 2 分、跟唱 1 分），主链永远干净不刷屏；每条语音旁自动生成"一起听"原唱入口，接对的歌沉淀为房间共享歌单，一键收藏到 QQ 音乐。

三层交互（主链接歌 / 同词归并 / 折叠评论）解决异步社交最大的敌人——刷屏；AI 文生图为每个字房间生成水墨意境背景板；渐进式技能卡（累计通过 3 次获得，而非抽卡）和炸弹歌/反向禁字等实时对战模式，让房间既是慢慢接力的暗号本，也是好友即兴 PK 的竞技场。

## 创作思路

1. **问题洞察**：飞花令天然适合音乐场景，但现有玩法（KTV 现场局、抖音对唱、微信群语音接龙）全部卡在"必须凑齐人、同时在线、没人当裁判"的门槛上。
2. **核心机会**：把实时聚会游戏改造成**异步永久房间**——这是被现有产品跳过的空白；实时对战保留为社群补充。
3. **差异化组合**：异步永久房间 + AI 裁判 + 三层不刷屏交互 + AI 水墨背景板 + 渐进式技能卡 + 炸弹歌对战，深度依赖 TME 曲库，别人抄不走。
4. **AI 能力矩阵**：AI 判官（识别/校验/查重）、AI 推荐官、AI 出题官、AI 意境背景板画师、AI 战绩海报画师、AI 故事卡——AI 不是点缀，是异步玩法成立的必要裁判。
5. **传播飞轮**：唱一句 → AI 生成战绩海报 → 社交平台分享 → 朋友扫码进房 → 再唱再分享，是冷启动关键。

## 评审三要素对照

- **用户价值**：解决"想玩接歌凑不齐人"的真实痛点——异步可参与、实时可竞技、战绩可晒、社群可沉淀；每个字房间都深度调用 TME 正版曲库（歌词校验、原唱片段、共享歌单导流）。
- **可行性**：聚焦房间玩法，不做双边冷启动；技术路径清晰（前端 H5/小程序 + ASR + LLM 歌词语义校验 + TME 曲库 API + 文生图，初赛以模拟数据演示完整闭环）；可内嵌全民K歌歌房，落地周期短。
- **创新性**："异步永久房间 + AI 裁判 + 三层交互 + 水墨背景 + 渐进式技能卡 + 炸弹歌"是组合创新。抖音已有用户自发玩炸弹歌（验证了需求），但没有任何产品把它做成结构化对战；反向禁字局、AI 出题局更是空白。

## Demo 说明（演示路径）

1. 首页：AI 推荐 + 今日飞花令大卡 + 按参与人数排行的字房间榜单（TOP3 徽标）
2. 进入「月」字局：AI 水墨意境背景板 → 规则条 → 共享歌单 → 三层交互主链（语音卡 / 同词归并 / 折叠评论）
3. 底部录音 → AI 判官模拟：识别歌词 → 含字校验 → 匹配原曲 → 首唱 +2 分新卡入链；再唱重复句 → 自动归并 +1 分
4. 点「一起听」：黑胶播放器弹层（原唱信息、**AI 合成副歌试听**、歌词高亮、加入共享歌单、跳转 QQ音乐）——Demo 用 Web Audio 合成旋律保证演示有声，正式产品调用 TME 正版曲库
5. 首页「+」自建房间：输入任意字（如「梦」）→ AI 背景板生成中 → 空房间花传到你
6. 完整闭环：唱一句 → 归并/计分 → 歌单沉淀 → 分享传播
