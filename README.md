# 飞花音 · Demo（全功能交互版 v4）

腾讯音乐首届高校 AI Hackathon「Build With AI」参赛 Demo  
赛道一（TME 产品创新功能）· 落地载体：全民K歌歌房 / QQ 音乐小程序

## 一句话

一个字就是一个永久房间：随时唱一句带这个字的歌词，AI 完成识别、校验、原曲匹配与查重；异步接力之外，还可发起五种实时对战并使用渐进式技能卡。

## 运行

方式一：直接双击 `demo/index.html`。  
方式二：本地静态服务器（推荐，录屏/麦克风权限更稳定）：

```bash
cd demo
python -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765
```

项目为零运行时依赖的纯静态 H5。自动验收地址：

```text
http://127.0.0.1:8765/index.html?autotest=1
```

## 已实现闭环

- **异步字房间**：首页发现、多维筛选、四种榜单排序、搜索、自建房间、持久化。
- **同主题创建决策**：输入已有主题时，可明确选择“进入已有主题房”或“创建同名新房间”；新房间使用独立 ID，歌单、互动和房主数据互不影响。
- **三层交互**：主链接歌卡、同词自动归并、折叠评论/表情/点赞；互动写入 localStorage，刷新后保留。
- **录音与 AI 判官**：MediaRecorder 真实录音，可选浏览器 SpeechRecognition；无麦克风自动降级。AI 判官展示识别文本、关键字校验、原曲候选、自动查重和首唱/跟唱计分。
- **一起听**：歌曲信息、歌词高亮、真实走动进度、Web Audio 合成试听、上一首/下一首、收藏、QQ 音乐搜索跳转。
- **实时对战**：标准接力、炸弹歌、反向禁字、AI 出题、多语言关键词；8 秒倒计时、对手回合、炸弹/水墨失败动画、历史战报。
- **技能卡**：禁句、求救、跳过、双倍、反转五种卡均可实际操作；每累计通过 3 首获得一张，持久化保存。
- **AI 能力**：推荐官、判官、出题官、故事卡、自建房意境背景板、战绩海报画师。
- **分享传播**：Canvas 真实生成 900×1350 PNG 海报，可下载或调用系统分享；支持浏览器屏幕捕获生成 WebM 精彩集锦。
- **长期社群**：加入/退出、群消息、贡献值、群内排名、约战入口、双击头像加好友。

## 演示数据说明

初赛版本使用本地曲库和模拟 AI 结果完成可操作闭环，所有数据保存在浏览器 localStorage。正式产品将按设计文档替换为 TME 正版曲库、ASR、LLM 语义校验、AIGC 文生图与账号体系。

## 验收结果

`?autotest=1` 已覆盖启动、筛选、字房间、录音判官、首唱/跟唱、评论点赞持久化、播放器、搜索、自建房、战绩海报、社群与实时对战，当前结果：`ALL PASS`。
