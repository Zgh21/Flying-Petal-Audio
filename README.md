# 飞花音 · Flying Petal Audio

以歌为令，以字会友 —— 不用同时在线的异步音乐飞花令

腾讯音乐首届高校 AI Hackathon「Build With AI」参赛作品 · 赛道一（TME 产品创新功能）

## Demo

- 在线体验：https://zgh21.github.io/Flying-Petal-Audio/
- 本地运行：双击 `index.html`，或 `python -m http.server` 后访问 127.0.0.1:8000

## 功能

异步字房间（AI 判官 / 同词归并 / 三层交互）· AI 水墨意境背景板 · 实时对战五模式（接力 / 炸弹歌 / 反向禁字 / AI 出题 / 多语言）· 技能卡系统 · 称号图鉴 · AI 战绩海报与战报 · 多维筛选 · 歌友社群 · 真实录音与回放 · AI 合成副歌试听（Web Audio）

详细设计见 `docs/飞花令产品设计文档.docx`；提交材料见 `docs/作品介绍-提交用.md`

## 自检

`index.html?autotest=1` 内置 68 项自动化测试（完整用户路径）。
